# Catalog-driven migration collection

Version 6 retains all 35 reviewed images with explicit category titles, pack
prices, effect labels and bounded motion. The collection is staged for the
one-time catalog-driven app rollout; do not publish it before that rollout.

Build and verify with `--collection remote-v6`. Future collections can have any
valid name and IDs. See [the GitHub authoring guide](../GITHUB_AUTHORING.md).
